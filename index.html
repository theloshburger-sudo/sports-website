ONE-TIME HOST SETUP

Connect your league.

BragBoard needs its Supabase URL and public publishable key before friends can create accounts and share a league. The public key is safe to ship only with the included row-level security policies; never use a service-role key here.

  1. Create a Supabase project and run supabase/schema.sql in its SQL Editor.
  2. Copy supabase/config.example.js to supabase/config.js.
  3. Paste the project URL and publishable/anon key, then publish this branch.

This app does not collect payments, create cash pots, or enforce debts. BragBoard coins are non-transferable points with no value.

How your private league works.

BragBoard flips the usual prize format: the lowest-ranked player is assigned the group’s unanimously approved, harmless, voluntary punishment. Winners get bragging rights and non-cash coins—not money or a prize.

  1. 1. Start or join a leagueCreate a group and share its private invite code, or enter a friend’s code to join theirs.
  2. 2. The host prepares the weekThe host loads real games from the sports your group selected. Friends can see the games once they are ready.
  3. 3. Everyone makes one pick per gameChoose exactly one winner for every listed game. Each pick automatically becomes final when that game begins.
  4. 4. The losers face the agreed punishmentAfter results are recorded, standings identify the last-place player or bottom three your group chose. Participation remains voluntary.
