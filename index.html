ONE-TIME HOST SETUP

Connect your league.

BragBoard needs its Supabase URL and public publishable key before friends can create accounts and share a league. The public key is safe to ship only with the included row-level security policies; never use a service-role key here.

  1. Create a Supabase project and run supabase/schema.sql in its SQL Editor.
  2. Copy supabase/config.example.js to supabase/config.js.
  3. Paste the project URL and publishable/anon key, then publish this branch.

This app does not collect payments, create cash pots, or enforce debts. BragBoard coins are non-transferable points with no value.

How BragBoard works

Start or join a private league. BragBoard loads real men’s professional games from the sports your host selected. Every member locks one winner per game before kickoff. Results update standings from locked picks. Coins are in-app points only: they cannot be bought, transferred, or redeemed.
