# TARGET: today's build

Choose the idea, person, interaction, and visual direction. The agent can help phrase and save your decisions after you approve them. The provided scope and review safeguards stay in place.

- **Thing:** BragBoard — a real private-league pick’em web app with accounts, invite links, weekly picks, monthly standings, unanimously approved voluntary punishments, and optional non-cash coins.
- **Audience:** Groups of friends who watch pro sports and want a simple, free season-long bragging-rights competition without fantasy-roster complexity or real-money stakes.
- **Requirements:** Authenticated members can create or join private leagues. Each member proposes a harmless voluntary punishment; only unanimously approved proposals enter selection. Choose shared or personal assignments, voting, wheel, or snake draft, and last place or bottom three before play. Server-enforce exactly one winner per displayed game before a game’s lock time. Award 10 non-cash coins to weekly winners and 20 to monthly winners; optionally spend 10 coins on one double-point pick per week before lock. Coins cannot be purchased, transferred, redeemed, or exchanged for value. Preserve sport-specific animations.
- **Guardrails:** Supabase Auth and a row-level-secured database are approved for private accounts, invitations, picks, and standings. Never commit a service-role key or a private credential; use only a public anon key in the browser with the supplied policies. No payments, cash pots, runtime AI, or unsolicited analytics. Label illustrative fixtures and results. Preserve the example and publishing setup. Work on a branch and wait for human review before shipping.
- **Experience:** A website-first, sporty dark-mode interface inspired by Sleeper’s bold clarity: condensed display type, black/charcoal panels, gold accents, subtle tiger-stripe texture, large game cards, and a prominent private-league leaderboard. First-time users see a clear sign-in and setup path. League setup uses an accurately numbered ten-question rounded onboarding with high-contrast selectable cards, Back/Continue navigation, and keyboard- and touch-operable explanations. Custom proposals use a blank textarea with no templates, suggestions, autocomplete, or automatic safety verdict. Everyone Votes requires unanimous settings and final-assignment approval; Host Decides reserves settings edits to the host without overriding unanimous punishment consent.
- **Test:** Exercise authentication configuration states, private-league creation and invitation rules, database row-level access, proposal and unanimous-approval gates, shared and personal selection, vote/wheel/snake order, visible assignments and voluntary opt-out, server lock enforcement, one-time rewards, and pre-lock power-up limits. Clearly label illustrative fixtures and results; verify the registered Pages URL only after approval and merge.
